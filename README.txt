LIAM CAR GAMES - Android V1

Contenido:
- Juego offline en HTML5 dentro de una app Android.
- 3 carros: rojo, azul y amarillo.
- Monedas, desbloqueos, niveles y récord.
- Guarda progreso localmente en el teléfono.
- Sin publicidad todavía (versión de prueba).

Para compilar:
1. Abrir esta carpeta con Android Studio.
2. Permitir que Android Studio descargue Gradle/SDK necesarios.
3. Build > Build APK(s).
4. El APK aparecerá en app/build/outputs/apk/debug/app-debug.apk.

Para Google Play después:
- Crear una versión firmada AAB.
- Añadir política de privacidad y configuración para público infantil.
- Integrar anuncios solo con SDK/configuración compatibles con Families.
